# 📚 Student Information Management

## Introduction

A Python task that uses a **nested dictionary** to store and manage student information such as register number, name, and marks.

## What I Did

* Stored student details using a **nested dictionary**
* Calculated **total and average marks**
* Assigned grades based on average marks
* Found the student with the **highest average**
* Calculated the **class average**
* Displayed students scoring above the class average
* Searched for a student using the **register number**

## Concepts Used

* Python
* Nested Dictionary
* `for` Loop
* `if-elif-else`
* User Input
* Dictionary Searching
* Basic Calculations
